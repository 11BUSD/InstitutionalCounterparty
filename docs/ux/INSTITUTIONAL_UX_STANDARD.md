# Institutional UX Standard

**Five seconds to understand. Five minutes to operate. Full forensic depth on demand.**

Every domain pack defines Executive, Operator, Expert, Counsel/Audit and Explain views, all from the same canonical state. Do not build one universal dashboard. Every vertical defines a 10-minute magic moment such as closed-file chronology, custody replay, banking exception diagnosis, private-asset passport, appraisal evidence review or metals provenance. UI may summarize complexity; it may not hide uncertainty.
