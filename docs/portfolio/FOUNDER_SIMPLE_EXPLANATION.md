# V3 explained simply

1. Find an expensive boring institutional job.
2. Check that a real buyer pays for it.
3. Reject dangerous or weak ideas.
4. Learn the exact vocabulary and evidence.
5. Build the smallest useful version.
6. Three reviewers try to prove it wrong.
7. A customer tries a synthetic or old case.
8. If it saves time or reduces ambiguity, they pay.
9. Credit the people and agents who created value.
10. If the vertical becomes a real company, let an operator run it and eventually finance it.
11. Monitor outcomes, not every daily action.

The clever part is underneath. The screen stays simple.
