# Threat Model

Treat users, customers, employees, models, agents, retrieved documents, translations, APIs, dependencies, integrations, reviewers, sources and counterparties as potentially faulty or adversarial. Priority threats: prompt injection, multilingual bypass, cross-tenant/domain leakage, unsupported claims, silent methodology change, unit/basis errors, malicious dependencies, excessive permissions, publication leakage, Git customer-data leakage, false reviewer consensus, replay/idempotency failure, rollback failure, misleading UI, stale standards and evidence manipulation. Mitigate with least privilege, deterministic action gateway, human approval, content-only parsing, versioned methodology, append-only audit, independent recalculation, provenance, dry-run defaults, kill switches, scans and rollback rehearsal.
